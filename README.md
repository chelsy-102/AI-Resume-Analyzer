# AI Resume Analyzer

A Python and Streamlit based resume analyzer that compares resumes with job descriptions and identifies matching and missing skills.

## Features

- Compare resume with job descriptions
- Identify matching skills
- Identify missing skills
- Calculate basic resume match percentage
- Simple and user-friendly interface

## Technologies Used

- Python
- Streamlit
